## 🚀 Getting Started

Clone the repo and open it locally — no build tools required.

```bash
git clone https://github.com/taniamehra006/Portfolio.git
cd Portfolio
```

Then simply open `index.html` in your browser, or run a local server:

```bash
# Using Python
python -m http.server 5500

# Using VS Code
# Right-click index.html -> "Open with Live Server"
```

## 🌐 Deployment

To make this live for free using **GitHub Pages**:

1. Go to your repo → **Settings** → **Pages**
2. Under "Source", select the `main` branch and `/root` folder
3. Save — your site will be live at:
   `https://taniamehra006.github.io/Portfolio/`
